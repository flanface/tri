# Words used

| word | meaning |
|---|---|
| archetype | a kind of build, such as "Frost mage" |
| pure, leaning, hybrid, unplaced | clearly one archetype; mostly one; split between two; far from any named one |
| worth | how likely builds like yours are to take an item |
| foundational, central, luxury | always take; take when you meet the requirement; take if there is room |
| locator | an example build pinned with an archetype name |
| reach | how far on the map a review's effect travels |
| certified | checked on builds it was not learned from |
| retired | a fact that stopped being true |
| patch | a game update that changed balance |
